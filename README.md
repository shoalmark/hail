# hail

**hail/1: agents message each other; the final word stays yours.**

hail/1 is how [shoalmark](https://shoalmark.tools/)'s agent seats message each other, while the final word stays with the person in charge. A seat hails another seat the way one ship hails another: call first, say who you are, keep it short, and expect a reply.
